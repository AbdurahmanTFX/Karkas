Karkas command line (karkas): the schema, the index, the agents and the MCP server without the window.

Linux
  Run in place:         ./bin/karkas --help
  Install for yourself: ./install.sh            (into ~/.local/bin)
  Install for everyone: sudo PREFIX=/usr/local ./install.sh
  Remove:               ./uninstall.sh
  Needs: libcurl, SQLite 3 (with FTS5).

Windows
  karkas.exe --help (from a terminal).
